# Desktop design records

These files are visual design records, not executable product surfaces and not
release evidence. Their example repositories, goals, files, counts, diffs, messages,
and results are illustrative only and must never be copied into the application as
fallback data.

For v1.0, a visible concept from these records must either be backed by real typed
application state and behavior or be removed from the current product design. The
shipped application must use honest empty, unavailable, loading, and error states;
it must not simulate success, activity, evidence, files, diagnostics, or progress.
